# 测试规范勘误与严格状态差异

1. N02原私有预期把`spectral_budget_bound`写为2000，这是非线性度下界，并非题目字段所指的谱幅预算。两独立执行者都返回96；公式为64+32=96，N下界为2048−96/2=2000。保留原预期副本，修正此字段为96；不是为了迁就某一执行者改变数学预期。原版严格结果也保留：with 27/30，without 24/30。
2. E07（Bent专用剪枝收到非Bent表）和E13（固定对齐方法被要求证明任意循环移位）原预期严格写status=error，两执行者均明确拒绝承诺并写not_applicable。这不产生错误数学结果，但未满足原字段断言；严格差异继续计为失败，不改成“严格通过”。
3. without的E12（缺多项式却要求唯一D容量）也返回not_applicable，原字段要求error；同样保留严格失败。
4. 数学/边界语义核验与严格字段断言分别报告。语义接受明确拒绝错误承诺，并不意味着原JSON断言通过。有效正常任务N11/N15若未完成构造，仍计未通过，不能因返回not_applicable而排除分母。
5. 第一轮30题为预先固定任务、同一执行环境、隔离agent上下文；没有旧技能版本。没有进行随机60/40隐藏集的完整模型优化实验。DS语义修复后另交新参数及范围拒绝回归，不能把它包装成完整统计泛化证明。
