# 零谱几何搬运：保持非线性度获得一阶弹性

## R — Reading

> “下面, 我们把 f 变换为 1 阶弹性函数.”

出处：《密码函数》第2章2.8，构造2.77及其后推导，书页125—131，尤其式(2.128)—(2.134)。书页加10为本PDF物理页。原例2.80码索引冲突已隔离，不用冲突索引生成函数。

## I — Interpretation

函数非线性度由最大绝对Walsh谱值决定，频率位置本身不影响这个指标。
平衡和弹性却要求特定位置的谱为零。
因此可以先寻找已有零谱点，再搬运谱位置，而不重新制造一套谱幅值。
给函数加输出线性项，使某个零谱点移到原点，即得到平衡函数。
如果平移后的零谱集合包含完整线性基，就能通过可逆输入变换让单位频率全部落入零谱。
原点及全部重量1频率为零，正是一阶弹性的判据。
真正困难的是找到平移后仍线性无关的零谱基，而非写出“进行仿射变换”。
该方法可返回可检查的δ和矩阵R；搜索失败必须保留失败范围。

## A1 — Application Example

**书中例题**：例2.80，p.131—133，提供8元函数的256位真值表及进一步转换；其码索引首段与后式不一致，禁止据矛盾索引重建。

**本项目明确标记的合成演练**：从该例提供的完整256位表出发，重新搜索δ及零谱基R，使用独立生成的转换见证，不照抄原例矩阵。已执行结果为转换后N=116、至少一阶弹性，见项目验证日志的zero_transport_n8。此结果支持给定实例，不证明任意高非线性函数均可转换。

## A2 — Future Trigger

- 用户已有一个高非线性函数，希望“保持非线性度改成平衡/一阶弹性”（preserve nonlinearity; balance; 1-resilient）。
- 用户问“零谱点够不够组成基”（zero-spectrum basis; rank certificate）。
- 用户尝试输入仿射变换后弹性丢失，需要定位“频率逆转置方向”（Walsh transport; inverse transpose）。
- 用户给定PS修补函数的真值表，要求实际δ、R及变换后函数，而不是只看存在性叙述。

与相邻能力的区分：直接从高重量系数构造函数用MM能力；已有函数的谱位置调整才用本卡。正规性剪枝寻找仿射子空间上的常值限制，与这里在频率集合中找线性基不同。要求t>1时，本卡仅提供需检查整个低重量球的判据，不承诺已有高阶转换算法。

## E — Execution

**输入契约**：n及长度2^n的二元真值表，或可对全部输入确定求值的生成器；明确整数下标与坐标位序。可选δ、R见证。目标为平衡或至少一阶弹性。不得默选有歧义的真值表编码；缺少编码时先取得说明。原书PS族的参数n模4及核条件必须单独核验，不能用本卡弥补不合法种子。

1. **固定运算约定并验表。** 在F₂中加法为异或。采用行向量，点积x·a=xaᵀ。以整数精确计算W_f(a)=Σ_x(-1)^{f(x)+a·x}，记录N_f=(2^n-max|W|)/2，并核验ΣW²=2^{2n}。若没有零谱点，停止：加线性项和可逆输入变换均不能制造零谱点。
2. **建立零谱集合O。** O={a:W_f(a)=0}。若用户仅要平衡，任选经验证δ∈O，令f₀(x)=f(x)+δ·x即可进入步骤5；否则按固定次序枚举O中的δ，避免不可复现的“随便选”。
3. **为每个δ寻找完整基。** 在O+δ中排除零向量，按固定次序作F₂高斯消元，保留每个提升秩的向量r_i。若最大秩小于n，换下一个δ。若穷尽全部δ仍失败，输出“该零谱搬运方案在给定函数上无见证”，附每个δ最大秩；这不是对其他真值表修改方法的不可能性证明。
4. **生成可逆变换。** 令R的各行为r_i，计算R^{-1}，逐项验证RR^{-1}=I。定义g(x)=f₀(xR^{-T})。从u=xR^{-T}推出x=uRᵀ，因此W_g(a)=W_{f₀}(aR)=W_f(aR+δ)。按这一式检查矩阵方向，不能用记忆交换R、Rᵀ或R^{-1}。
5. **闭环核验。** 独立从g的真值表重算谱；检查W_g(0)=0。若目标是一阶弹性，再检查每个单位向量e_i处谱为0；比较N_g=N_f。所有运算用整数，零判定不设浮点容差。若用户还要求次数、AI/FAI或实现成本，分别实测，不能从本证明推断。
6. **交付证书。** 输出输入表摘要、位序、δ、R及逆、原/新N、各重量≤1频率值、变换公式、g的生成器或真值表。若采用限制搜索而非穷尽，输出已搜范围和剩余范围。资源math_tool.py的zero-transport与inspect可辅助生成和独立检查；卡片步骤是算法依据，工具输出必须符合上述契约。

**完成标准**：成品函数与可复算δ、R齐全，谱搬运等式及目标低频逐项成立；失败时有明确合法性或秩见证。

## B — Boundary

- 不保证任意函数的零谱集合含可搬运完整基；Bent函数无零谱点，不能仅靠此变换变平衡。
- 一般可逆输入变换保持非线性度，但不保持坐标意义下的弹性。本卡是有目标地检查低重量频率，不能省略。
- 更高阶要求W_f(aR+δ)=0对全部wt(a)≤t成立；n个独立零点不够。
- 源函数的高AI/FAI、次数或其他结构不由本卡保证；不能将有限实例转换成功写成新函数族定理。
- 原版例2.80索引需校勘，作为输入应使用明确的真值表或经过独立验证的合法生成器。

相关能力：依赖单输出谱检查；与MM构造对比；可与正规性筛查组合分析转换前后的结构，但两者检查不同性质。
