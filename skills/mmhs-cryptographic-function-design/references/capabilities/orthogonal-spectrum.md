# 部分线性零件的正交谱级联

## R — 原文

> “用若干正交谱函数集作为构造密码函数的‘零件’。”

《密码函数》2.3节，引理2.31、构造2.32、定理2.33，p.69—72；公式(2.47)—(2.55)。本卡仅覆盖原始层构造及非线性度下界，次数最优化变体2.35/2.38不在已验证执行范围。

## I — 自述

- 部分线性函数把线性系数当成频谱切片标签。
- 标签不同的零件，在同一频率上不会同时有非零谱值。
- 因而同层级联时，谱幅值只付出一个零件的代价。
- 为补足合法零件数量，可使用不同尺寸Bent核形成多个层。
- 不同层之间可能同时贡献，所以必须累加层级预算。
- 弹性来自每个零件的高重量线性系数，并由级联保留。
- 构造的难点是容量、核性质和单层支撑接口共同合法。
- 最后给的是保证下界，实际函数可以比下界更好。

## A1 — 应用例

**原书类型：一般构造。** 构造2.32使用Γ₀仿射层和Γ_u部分线性Bent层，定理2.33证明其弹性及非线性度下界；原书2.3还给参数实例。本卡不把未复算的整张参数表作为证据。

**合成演练，非原书例题：** n=12、t=1、d=n/2=6。Γ₀有64−1−6=57个重量>1的6维系数；u=1层用r=4位线性系数和核h(v₁,v₂)=v₁v₂，有16−1−4=11个合法标签。选择Γ₀全部57个、Γ₁任意7个不同标签，填满64个选择器。层谱预算为64+32=96，故N≥2048−48=2000，至少1阶弹性。这个结果是下界，不声称选任意7项都精确N=2000。

## A2 — 触发与邻卡区别

1. 合法线性零件数量不足：“补充非线性零件”“nonlinear concatenation pieces”。
2. 需要让小核互不叠谱：“正交谱”“disjoint spectral supports”。
3. 要控制多层级联非线性度：“layer budget”“Walsh peak bound”。
4. 给定Bent核，希望组合弹性函数：“partially linear”“resilient concatenation”。

纯仿射同尺寸零件优先`mm-spectrum`。不同自由变量个数的块属于`gmm-budget`；本卡所有被级联零件都有d个输入，只是内部线性/非线性拆分不同。几何子空间不相交码的生成交由`disjoint-codes`，本卡不需要那种码支撑。

## E — 执行

**输入契约。** n≥6为偶整数、t≥0、目标层集合或允许自动选择；每个u层给定2u元Bent核h_c（表或生成规则）。自动核实现可明确采用Σv_{2j}v_{2j+1}，这是标准Bent核的合成选择，不冒充书中特定表。位序固定X低d位、Y高d位，层中U为X高r位、V为低2u位。缺核时先询问，或在用户允许通用核的任务中明确该实现约定。

1. **列合法层。** d=n/2，e=floor((n−2t−2)/4)。Γ₀={c·X:wt(c)>t}；u=1,…,e时r=d−2u，Γ_u={c·U+h_c(V):wt(c)>t}。容量分别C₀=Σ_{j=t+1}^d binom(d,j)、C_u=Σ_{j=t+1}^r binom(r,j)。r≤t时该层无可用标签。容量总和不足2^d则停止并报告缺口。
2. **验证核。** 每个h_c都检查完整Walsh绝对值恒2^u；不满足则不能使用Bent层谱预算。选择不同核也可以，但同层每个标签c最多使用一次。生成器参数与核哈希保存在输出中。
3. **选择零件。** 选若干合法层，在容量限制内填满恰2^d个不同零件，保留(Y→层u、系数c、核)表。默认可按层顺序取满直到末层补足，此为明确实现策略；若声称遵照原书最小二进制选择，必须记录位权与所得U，避免混淆两种策略。报告任何合法选择的对应预算。
4. **级联。** 对选择器Y调用其零件g_Y(X)，令f(Y,X)=g_Y(X)。被选择的零件需要完整定义于F₂^d，不允许把缺失位当0。
5. **证明正交谱。** 对u≥1，W_{g_c}(δ,θ)=Σ_U(-1)^{(c+δ)·U}W_{h_c}(θ)，故δ≠c时0，否则2^r W_h，非零幅值2^{d−u}。u=0层是单点幅值2^d。由此同层的带符号和最多一个非零项；全谱W_f(β,α)=Σ_Y(-1)^{β·Y}W_{g_Y}(α)。
6. **给界与弹性。** 令实际使用层为U，max|W_f|≤Σ_{u∈U}2^{d−u}，故N_f≥2^{n-1}−Σ_{u∈U}2^{d−u−1}。若wt(β,α)≤t，则每层频率线性部分重量≤t，无法等于合法c，因此全谱为0。此步骤不要求跨层支撑不交。
7. **实测。** 对可枚举实例整数FWHT，检查低重量零谱、实测峰值不超过预算、Parseval及ANF次数。通用资源`math_tool.py`的`inspect`可检真值表；本卡的零件选择与层预算须由执行者显式保存。

**完成标准。** 交付合法核、容量表、所选零件/层表、f、同层正交谱公式、非线性度下界、实测值（若完成）及其差别。所有计数与谱值精确整数，不作浮点近似。

## B — 边界

“正交谱”指逐频率支撑不交，不是两谱内积为零。核不是Bent、同层重复系数、仅按名称估算容量均会破坏谱预算。跨层三角界不自动取等；未给共同达到频率不能报告精确N。代数次数优化需另外验证最高项与新增谱扰动，不能静默加单项式。对任意小核的HML分层属于待核查扩展。

**相关能力。** 与`mm-spectrum`对比线性零件；与`gmm-budget`对比外部块尺寸；依赖指标检查能力核验核与成品，单输出任务不需要全输出组合枚举。
