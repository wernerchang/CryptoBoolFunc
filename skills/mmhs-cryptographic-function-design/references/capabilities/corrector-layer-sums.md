# 用按重量分层的谱和验证偏差校正器

## R — Reading

> “非线性t阶弹性函数f都是(n,1,t)校正器, 但(n,1,t)校正器未必是t阶弹性函数。”

出处：《密码函数》4.4，引理4.25及其后说明，书页257—258。引文仅排版归一化。V1采用引理4.25的零和条件；同页引理4.23印刷符号冲突不收入active公式，以下偏差展开是依据明确概率约定重新推导。

## I — Interpretation

输入位独立且各有同一偏差e时，输入字符的期望只取决于字符重量。
于是相同重量的所有频率贡献到同一个e的幂次。
只要这一重量层的Walsh值相加为零，该阶偏差就被消去。
弹性要求每一个低重量谱值单独为零，比层和为零更强。
所以校正器可依靠正负抵消获得高于其弹性阶的校正阶。
多输出校正器必须对每个非零输出线性组合使用同一判据。
“t阶”首先表示低至t次项全消，不能自动理解为恰好t阶。
如果各位偏差不同或输入相关，这个单变量层和机制一般失效。

## A1 — Application Example

**原书worked_example：** 例4.30，p.260，α=011、β=110，以x₄选择两个仿射核，函数为二次、1阶弹性、2阶校正器而非2阶弹性。该例以非零低重量谱的层内抵消区分两个条件。

**合成演练：** 构造4.28的另一n=4实例，α与β按本地固定位序取两个不同重量2向量；完整谱层和在重量0、1、2处为0，重量3处非零，故校正阶恰2；最低非零谱重量为2，故弹性阶恰1。父任务还以不同e_i直接枚举概率，核对多变量展开，说明原同偏差抵消不能随意推广。

## A2 — Future Trigger

- 用户要判定有偏源的后处理函数：“bias corrector / 偏差校正阶”。
- 用户发现弹性阶较低，仍希望提高偏差消除阶：“weight-layer cancellation / 层内抵消”。
- 用户要输出偏差多项式：“output bias polynomial / Walsh层和”。
- 用户要检查多输出每种线性组合：“all nonzero components / 多输出校正证书”。

近邻区分：`vector-contract`核验联合平衡与谱的逐点零条件；本卡核验按重量求和，二者不可互代。`double-code-corrector`是带生成算法的特定结构；本卡既可验证该结构，也可验证任意给定小维真值表，但不自动构造双等距码。

## E — Execution

**输入契约：** n、布尔函数表或(n,m)生成器、输入源模型。默认仅接受输入位统计独立且Pr(x_i=0)=1/2+e、Pr(x_i=1)=1/2-e的共同偏差；定义Δ=(Pr(f=0)-Pr(f=1))/2，e为符号变量或精确有理数且|e|≤1/2。需明确所有变量及输出位序，不得把其他偏差约定静默套入公式。

1. **模型分支。** 输入相关则停止使用本判据；不同e_i时转为多变量概率计算并明确不继承“同偏差校正阶”结论。若用户只要同偏差理论设计，无需假造现实熵源数据。
2. **计算谱。** 对单输出取W_f(a)=Σ_x(-1)^{f(x)+a·x}；对多输出枚举全部c≠0，f_c=c·F，计算整数FWHT。检查W_{f_c}(0)=0；不平衡则不满足本书校正器定义。
3. **按层求和。** 对每个c、j=0,…,n，令S_{c,j}=Σ_{wt(a)=j}W_{f_c}(a)。使用整数求和，零容差为严格0，不用浮点阈值代替。
4. **明示概率推导。** 独立同偏差下E[(-1)^{a·X}]=(2e)^{wt(a)}，Walsh反演给Δ_c(e)=2^{-n-1}Σ_j S_{c,j}(2e)^j。此为本卡按约定重建的公式；不得引用印刷引理4.23中的冲突符号作为已核公式。
5. **求阶与分支。** 找最小j使S_{c,j}≠0，令t_c=j-1。检验“至少t”只需S_{c,0…t}=0；声称“恰t”另需S_{c,t+1}≠0。多输出保证阶为min_{c≠0}t_c。另按最低非零谱重量算弹性阶，分栏报告，不能混称。
6. **数值校验。** 小n可用有理数e直接枚举输入概率，验证Δ与多项式一致；异偏差时应使用Δ_c(e₁,…,e_n)=2^{-n-1}Σ_a W_{f_c}(a)∏_{i:a_i=1}(2e_i)。资源`math_tool.py`的`corrector`及`inspect`可复算层和。

**输出契约：** 源模型、偏差定义、n/m/位序、每个c的全部层和、精确偏差多项式、最低非零阶、至少/恰好标记、弹性阶与非线性度另列、必要时精确概率样点。完成标准为全部非零分量通过所需低阶零和检查，模型与公式一致；缺分量不可宣称多输出验证完成。

## B — Boundary

本卡不是任意弱随机源提取器，也不保证独立于侧信息的随机性或增加熵。输入独立同偏差的假设不能由输出平衡代替。改变输入位的任意可逆线性组合会破坏该源模型；同一函数的校正阶也不是一般EA不变量。只消掉低阶项不代表所有e下输出完全无偏。引理4.23原版冲突只隔离公式，不否定4.25的层和判据。

相关能力：依赖`vector-contract`；组合`double-code-corrector`生成后复核；与逐点低重量谱零的`mm-spectrum`对比。
