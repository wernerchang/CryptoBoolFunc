# 置换标签驱动的PS多输出Bent构造

## R — Reading

> “由构造3.13 得到的 (n, n/2) 函数 F 是多输出 Bent 函数.”

出处：《密码函数》第3章3.2，书页172—173，构造3.13及定理3.14；所用单输出PS判据见第2章p.125引理2.76。此卡采用一般构造，隔离原例中的错误码编号。

## I — Interpretation

取n=2k，把非零输入空间划成2^k+1个互不相交的k维线性码的非零部分。
其中一个码保留为自由码，其余2^k个码用k位标签一一编号。
用一个k位置换H把标签变成输出值，在同一码的非零字上输出固定的H标签。
任意非零输出组合c·H都平衡，因此恰选择一半标签。
相应大函数的支撑便是恰好2^{k-1}个码的非零部分之并。
单输出PS判据使每个这样的分量都是Bent，且同一标签结构保证所有组合同时成立。
该函数的各分量不平衡；自由码的全零输出正为后续递归平衡改造留出了位置。
构造价值在统一的输出标签机制，不能由分别拼凑几个Bent坐标替代。

## A1 — Application Example

**书中一般构造**：构造3.13、定理3.14，p.172—173。书中例3.15另给(8,4)表，但本卡不复用未独立验证的例表或可能冲突的索引。

**本项目合成演练**：n=6,k=m=3，使用GF(8)、p(z)=z³+z+1。在F₂³×F₂³上取C_a={(x,ax):x∈GF(8)}（a∈GF(8)），自由码C_∞={(0,y)}；标签置换H为恒等。对x≠0输出F(x,y)=y/x，对x=0输出0。每个c≠0在8个标签中选择4个码，支撑大小4×7=28；由PS谱判据，所有分量谱幅8，N=28。这是可复算合成演练，不宣称对应书中某一真值表。

## A2 — Future Trigger

- “生成多输出PS型Bent函数”（vectorial PS Bent; partial-spread construction）。

- “需要可供自由码递归修补的Bent底函数”（free-code seed; recursive balancing）。

与相邻能力的区分：用户要求平衡多输出函数，应使用自由码递归嵌入能力并按其种子条件执行；本卡输出的Bent族不平衡。需要奇数维平衡半Bent时考虑DS。已有任意函数只需要指标检查时，使用多输出验证契约，不启动新构造。

## E — Execution

**输入契约**：偶数n=2k、k≥2；一个完整(n,k)spread——2^k+1个k维子空间及其中一个自由码；其余码与F₂^k之间的双射标签；k位置换H的完整输出表。可选输出维数m≤k及满秩线性投影P:F₂^k→F₂^m。默认构造输出k维；投影是明确的推导扩展，不能静默删坐标改变用户目标。

1. **验证代数对象。** 对每个生成矩阵检查秩k、环境长度n；任意两子空间交集仅零。每码非零部分有2^k-1个元素，总数(2^k+1)(2^k-1)=2^n-1；结合不交性证明覆盖全部非零输入。小参数实际枚举交集，大参数可用域图码的结构证明。若只有“很多不相交码”而数量不足，停止，不把残缺集合当spread。
2. **固定标签和自由码。** 非自由码必须恰2^k个，一一分配标签a∈F₂^k；自由码不参与该标签列表。检查H是k位空间置换，每个值恰出现一次。记录输入/输出坐标与标签编码，零标签所指的是一个完整子空间，不等于公共原点。
3. **定义函数。** F(0)=0；对x∈C_a\{0}定义F(x)=H(a)；对x∈C_∞\{0}定义F(x)=0。这一定义等价于书中按各h_i支撑选择对应码的非零部分。不同码共享原点，仅在原点作一次定义，不能按码重复赋值。
4. **证明全部分量。** 任取c≠0，由H置换可知h_c(a)=c·H(a)平衡，故#{a:h_c(a)=1}=2^{k-1}。于是supp(c·F)=并_{h_c(a)=1}(C_a\{0})。应用引理2.76的PS−条件，得到W_{c·F}(ω)∈{±2^k}，N_{c·F}=2^{2k-1}-2^{k-1}。必须保留任意c量词，不能只证明输出坐标。
5. **若投影到m维。** 先检查P秩m，再令G=P∘F。任意d∈F₂^m\{0}经Pᵀ得到非零k位系数，因此d·G仍是F的某非零分量，继承Bent。这一步要求输出线性投影满秩；任意非线性输出后处理不在保证范围。
6. **实际核验与交付。** 小规模独立生成完整函数表，按多输出验证契约检查全部非零分量，比较谱幅、N、支撑大小；记录不平衡事实。输出spread生成法或矩阵、自由码、标签表H、可选P、函数求值算法、统一分量证明及实测范围。资源math_tool.py的ps可辅助；调用前核对该资源当前参数实际支持的构造分支，不把其他PS递归命令结果冒充本卡原始Bent底函数。

**完成标准**：合法完整spread、置换标签与函数数据齐全；全称证明支持每个非零分量Bent，实测部分与证明相符。若使用域图码求值，须验证域除法和零输入分支。

## B — Boundary

- 原始PS多输出Bent函数不平衡，不能直接交作平衡或置换S盒；尤其m=k<n，不具备同维置换条件。
- 不能任意选几个标量Bent函数作坐标就得到多输出Bent，输出组合可能不Bent。
- 完整spread与标签置换是构造前提，不以输出谱碰巧良好代替对象合法性。
- 本卡不声称次数、AI/FAI或差分均匀度最优，也不自动保持经过任意非线性输出变换后的性质。
- 错误原例编号或未核验真值表不得作为生成器输入；本卡给一般构造与独立合成例。

相关能力：依赖不相交码生成及多输出验证契约；与自由码递归平衡能力组合；与DS平衡半Bent能力按目标性质对比选择。
