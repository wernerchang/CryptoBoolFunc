# 将序列集相关转换为函数和的Walsh谱

## R — Reading

> “正交序列集S_f和S_g之间的互相关值问题就转化为非线性布尔函数f+g的非线性度问题。”

出处：《密码函数》第4章4.1，式(4.2)，书页224—226；特定集合构造见4.2—4.3，p.228—254。

## I — Interpretation

把布尔值f(x)编码成±1序列s_f(x)=(-1)^{f(x)}。
加一个线性函数a·x，相当于用对应线性序列逐位覆盖。
同一f覆盖不同线性函数时，内积中的f出现两次并相消。
因此集内正交由非零线性函数的字符和为零保证。
不同覆盖函数f、g之间，相关由f+g的谱决定。
高N_f与高N_g各自并不足够，必须检查N_{f+g}。
线性标签受限时只访问部分谱，整谱最大值仅给上界。
这是一种固定对齐内积接口，不自动涵盖循环移位相关或网络分配图。

## A1 — Application Example

**原书worked_example：** 例4.2，p.226，(4,2)Bent函数F的三个非零分量f₁、f₂、f₁+f₂分别覆盖全部4元线性函数，与线性集合一起得到4个正交序列集，各16条长度16序列，跨集合内积为±4。

**合成演练：** 取n=4、f=x₀x₁+x₂x₃、g=0，全部标签a,b∈F₂⁴。逐一核对256对内积等于W_f(a+b)，最大绝对值4。演练仅验证该固定对齐任务，不是原例两分量真值表的复刻。

## A2 — Future Trigger

- 用户要从布尔函数族生成正交序列：“orthogonal sequence sets / 线性覆盖”。
- 用户已有序列集，要求解释跨集合相关：“cross correlation / Walsh certificate”。
- 用户想借高非线性控制相关上界：“从nonlinearity到correlation”。
- 用户限制频率标签，希望挑互相正交的集合：“restricted linear labels / 频谱零点分配”。

相邻区分：`ds-semibent`和`ps-recursive-balance`提供函数，不能直接替代函数和的相关核查；`vector-contract`提供分量谱检查。本卡不承接尚未验证的蜂窝分配图、复用距离或任意时移优化。

## E — Execution

**输入契约：** n、布尔函数f_i的完整表或确定性生成器、每集线性标签集合L_i⊆F₂ⁿ、序列坐标顺序；相关定义必须为固定对齐的未归一化内积。若用户要求循环/非循环移位或归一化相关，先标记为扩展任务并单独定义，不能沿用本卡默认结论。

1. **固定编码。** 设s_{i,a}(x)=(-1)^{f_i(x)+a·x}，x按明确位序排列。若归一化，保存未归一化值后再除2^n。
2. **集内检查。** 同一i且a≠b，内积为Σ_x(-1)^{(a+b)·x}=0；标签重复应报重复序列，不能算作两条独立正交序列。
3. **跨集转换。** 对i≠j，构造h=f_i+f_j，计算W_h；逐对相关C(s_{i,a},s_{j,b})=W_h(a+b)。若函数由多输出F的分量产生，使用f_c+f_d=f_{c+d}，仍检查c+d≠0。
4. **取正确最大值。** 实际集合相关为max_{a∈L_i,b∈L_j}|W_h(a+b)|。若两标签集都是全空间，则等于max|W_h|=2^n-2N_h；标签受限时只对L_i+L_j取最大，整谱值仅为上界。
5. **生成证书。** 输出每集大小、长度、标签唯一性、集内正交检查、各跨集相关最大值和达到标签对。需要“集间正交”时，要求所有允许标签和都落在W_h的零点集合。
6. **复算。** 小规模同时用直接内积与FWHT核对；资源`math_tool.py`的`sequence`可重复这一过程。两种计算不一致先检查±1编码和标签位序，不发布结果。

**完成标准：** 所有实际集合对均有完整相关值或等价的谱支撑证书；精确最大值附达到的标签对。未验证分配图只交序列层证书，不附工程复用保证。

## B — Boundary

固定对齐正交不能推出任意时移正交；集内正交不能推出所有集合间正交。各个f_i高非线性不能替代所有f_i+f_j的谱检查。序列集的标签限制会改变是否达到整谱上界。蜂窝布局、相邻冲突、复用距离需另行图模型与验证，不包含于本卡已验范围。

相关能力：组合`vector-contract`以取得全分量谱；可接受`ds-semibent`或`ps-bent-labels`输出；和`corrector-layer-sums`共享谱数据但验收目标不同。
