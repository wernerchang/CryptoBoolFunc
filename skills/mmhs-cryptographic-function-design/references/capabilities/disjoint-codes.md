# 不相交图码与半维spread证书

## R — 原文

> “用构造2.70中的方法可以得到2^{u−m}个(u,m)不相交码，但这不是在F₂^u中所能找到的不相交码的最大数量。”

《密码函数》2.7节，构造2.70、定理2.71，p.119—121；码距筛除及示例p.121—124。引文公式已按数学记号规范化。能力范围是合法图码、半维spread及书中递归补码口径，不宣称全局最优数量。

## I — 自述

- 把域乘法图像写成二元线性子空间，就能系统生成只交于零的码。
- 每个码保留相同消息坐标，并把域乘法结果放在后缀。
- 两码有公共码字时，先由消息坐标得到相同消息，再用域无零因子排除非零交点。
- 图码没有使用零消息前缀、非零后缀的空间，可在该处继续补码。
- 半维情形补一个完整后缀子空间，就恰好覆盖全部非零向量。
- 码距不是仅由不相交性保证，必须独立计算或证明。
- 递归生成数量是该方法的可实现容量，不是所有构造的全局上限。
- 所有下游函数构造都应保存生成矩阵、域表示和交集证书。

## A1 — 应用例

**原书类型：一般构造。** 构造2.70给G_i=(I_m|R_i)，R_i各行是连续本原幂的坐标；另加(I_m|0)。定理2.71在剩余零前缀空间递归补码。

**合成演练，非原书编号实例：** u=6、m=3、GF(8)=F₂[x]/(x³+x+1)，C_z={(a,az):a∈GF(8)}，z遍历8个域元素。再加C_∞={(0,b):b∈GF(8)}。9个3维子空间各有7个非零字，任意两交仅零，9×7=63=2⁶−1，因此为完整半维spread。这里并未声称每码具有某个大于1的共同最小距离。

## A2 — 触发与邻卡区别

1. 需要PS/DS的底层子空间族：“不相交码”“disjoint linear codes”。
2. 需要划分所有非零向量：“spread”“half-dimensional partition”。
3. 需生成矩阵和严格交集证明：“graph code”“finite-field multiplication”。
4. 希望给函数零件增加码距约束：“minimum distance”“筛除低重量码”。

本卡处理子空间与码，不生成布尔函数本身；PS支撑/自由码递归和DS搬运应使用对应卡。仅需输入前缀划分时使用`prefix-partition`，它与码不相交是不同结构。多输出GMM阵列还需要对任意非零列组合保持单射，不能只交付不相交码就声称完整构造成立。

## E — 执行

**输入契约。** 整数u≥4、m≥2、u≥2m；指定GF(2^{u-m})的既约/本原多项式及坐标基。图码枚举可用所有域元素而不依赖本原幂标签，但若照书按幂枚举，必须验证所选γ阶为2^{u-m}−1。可选目标距离d。缺域多项式时应询问或明确自动搜索合法多项式并输出证书；不能猜一个不可约就称本原。坐标约定：多项式系数对应低位到高位，输出码字由m位消息与v=u−m位后缀拼接，具体整数字段顺序须记录。

1. **核域与基。** 以模多项式加法/乘法计算；验证多项式次数v、不可约性，及所需本原阶。消息域嵌入a(μ)=Σ_{j=0}^{m-1}μ_jγ^j；因m≤v，基的前m项线性无关，嵌入单射。若使用自定义基，直接核秩m。
2. **生成图码。** 对每个z∈GF(2^v)，定义C_z={(μ,π(z·a(μ))):μ∈F₂^m}。生成矩阵G_z=(I_m|R_z)，其中第j行右侧π(zγ^j)。z=0即(I_m|0)，z非零对应原书连续幂族（索引可重排）。检查每G秩m、每码恰2^m个码字。
3. **证明交集。** 若(μ,za(μ))=(ν,z'a(ν))，由前缀μ=ν；z≠z'则(z+z')a(μ)=0。域无零因子得a(μ)=0，嵌入单射得μ=0，所以交集只有零。可枚举规模直接复核码字集两两交；较大规模用秩([G_z;G_z'])=2m作为等价证书。
4. **半维spread分支。** 若u=2m，加入C_∞={(0_m,b):b∈F₂^m}，其生成矩阵(0|I_m)。它与任一图码的交也仅零。总非零计数(2^m+1)(2^m−1)=2^u−1，结合不交推出覆盖。保存“计数+不交”的覆盖证明，不能只数码字而不查交。
5. **一般递归分支。** 若u>2m，图码未用的非零部分位于0_m×F₂^{u-m}。在这个后缀空间重复同样构造，只要剩余维度仍≥2m；剩余维度r满足m≤r<2m时选一个明确m维子空间作为最后一码并终止。每一层前置已消耗的零坐标，核对跨层非零码字的首个消息块位置不同。书中方法得到Σ_{j=1}^{floor(u/m)-1}2^{u-jm}+1个码；这是构造所得口径，结果实际生成数须核对此式。
6. **距离分支。** 若要求最小距离≥d，对每码枚举非零消息并取最小wt(μG)，或提供能覆盖所有非零消息的结构证明。剔除不达标的码，保留新容量与被删理由；删码后一般不再是完整spread，不得沿用全非零覆盖结论。d=1时也要保证秩而非接受零码。
7. **输出。** 交付域多项式/基/位序、矩阵族、每码维数和距离、交集/秩证书、递归层次与数量，以及是否完整spread。资源`math_tool.py`的`codes`命令可生成和核查；只对该命令实际支持的参数范围报告实测，其他递归层须另保可复算证据。

**完成标准。** 每码线性且秩m，所有不同码仅交零；若声称spread，另有完整非零覆盖；若声称距离d，所有非零字均已覆盖验证。整数/二元运算，无浮点容差。参数或域验证失败时返回具体多项式、秩或公共非零码字见证并停止。

## B — 边界

不相交码不是“所有码字都不同”：零码字在每码均出现，必须排除零后比较。u<2m时两个m维子空间不可能仅交零，不应继续图码族承诺。一般m不整除u时，末尾残余空间可能未全覆盖，不能称spread。筛距离减少容量；换坐标的任意可逆线性变换可能改变汉明重量，不能默认保码距。书中M(u,m,d)及本算法计数不证明全局最优。

**相关能力。** 是PS构造、PS递归与DS支撑搬运的真实代数依赖；与向量阵列能力组合为多输出GMM提供码族；与`prefix-partition`只有“生成不交块”的表面相似，数学对象与验收不同。
