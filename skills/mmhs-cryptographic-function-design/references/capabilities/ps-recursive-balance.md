# 自由码递归嵌入实现多输出平衡

## R — Reading

> “进行真值表修改时, 我们只修改自由码中向量对应的函数值。”

出处：《密码函数》第3章3.2，构造3.16、定理3.17，书页173—175（PDF183—185）。引文略去原文码下标，仅保留句义；数学对象以如下定义为准。例3.18的索引印刷冲突不作为算法输入。

## I — Interpretation

PS构造把非零输入分配给半维不相交码，每个码由标签向量决定输出。
标签的任意非零线性组合平衡，因此恰好选中一半非自由码。
每个选中码缺少零向量，使该分量的支撑比平衡要求略少。
自由码提供一个完整的小维空间，用于补入一个已知平衡分量。
补入支撑的大小恰好抵消缺额，所以平衡性可逐层归纳。
输入维数每层翻倍，输出维数保持为m。
谱峰由各层贡献预算控制，定理给下界时不能直接写成精确非线性度。
关键设计自由度是合法spread、标签投影和小维平衡种子，均需固定坐标。

## A1 — Application Example

**原书worked_example：** 例3.18，书页174—175，m=3、递归两层，由3位AB置换种子扩展到6位再到12位，原例报告谱峰76、非线性度2010。p.175末码索引与维数不符，应依据构造3.16按实际维数生成完整spread。

**本地同族演练，非逐位复刻原例：** 固定种子表 `[0,1,3,4,5,6,7,2]`，分别使用GF(8)和GF(64)图码spread及固定3位标签投影。枚举4096个输入、7个非零分量，输出向量各出现512次，最小非线性度2010。不得把同族指标相同写成真值表相同。

## A2 — Future Trigger

- 用户希望从小维置换种子生成大维平衡多输出函数：“自由码递归 / recursive free-code embedding”。
- 用户已有spread或PS型Bent族，希望修补平衡：“把PS Bent改成平衡 / balance a PS construction”。
- 用户比较递归层数和输出比例：“保持m不变，把n翻倍 / dimension doubling”。
- 用户要求完整平衡计数与谱界：“全部分量平衡证书 / component-wise balance certificate”。

相邻区分：`ps-bent-labels`负责未经平衡修改的PS Bent族；本卡负责在自由码嵌入平衡种子。`ds-semibent`以奇数维AB核和谱支撑搬运维持半Bent性质，不能由本卡代替。`vector-contract`负责联合平衡量词与可行性前检。

## E — Execution

**输入契约：** m≥3、层数k≥1、n=2^k m；种子F⁽⁰⁾为m位置换，若引用定理3.17的具体界，须验证种子达到书中规定的非线性度；每层GF(2^u)的不可约/本原多项式、向量基、输入及输出位序；标签投影P_u:F₂^u→F₂^m须满秩。缺少这些数据时先固定并明示实现约定；不能静默沿用某张有索引疑点的原表。

1. **验证种子。** 枚举全部2^m输入，确认输出无重复；计算每个c≠0的Walsh谱与N。若不达定理要求，可继续生成平衡族，但不沿用该定理的特定谱界。
2. **生成一层spread。** 在u维域上构造C_a={(x,xa):x∈GF(2^u)}，a遍历全部域元素，另取C_∞={(0,y)}。验证每码维数u、交仅零，非零字总量(2^u+1)(2^u-1)=2^{2u}-1。
3. **定义输出。** 选定一致坐标，以F_new(0,y)=F_prev(y)填自由码；x≠0时令a=y/x，F_new(x,y)=P_u(a)。这是一般构造的一种明确实现，不是原书真值表位序的隐含复刻。
4. **证明平衡。** 固定任意c≠0，c·P_u为非零线性函数，选中2^{u-1}个标签。非自由支撑贡献2^{u-1}(2^u-1)，自由码贡献2^{u-1}，总为2^{2u-1}。输出每层的这一计数和所有分量量词。
5. **谱预算与复算。** 若小参数允许，生成全部真值表并对2^m-1个分量做整数FWHT。分别保存实测max|W|和理论预算；使用定理3.17时报告N_F≥2^{n-1}-Σ_{j=1}^k2^{n/2^j-1}-2^{floor(m/2)}。没有达到性证据只写下界。
6. **迭代及验收。** 将u翻倍，重复至n。可用资源`math_tool.py`的`ps`和`inspect`复算，资源不替代上述计数与合法性论证。

**输出契约：** JSON或Markdown记录n,m,k、种子表、各域多项式与基、投影矩阵、分层生成规则、spread证书、所有分量平衡/N/min及max次数、理论界/实测值分栏、源版本疑点。完成标准为生成器可复跑、无输入漏点、每个输出出现2^{n-m}次、所有非零分量已核验或有统一结构证明。

## B — Boundary

不把高非线性度推出低差分或置换S盒性质；n>m时该函数本身不是同维置换。一般平衡种子足以支持平衡计数，但种子谱不满足条件时不能继承原定理数值界。大维FWHT不可行时标记验证规模，不伪造全量实测。原例p.175索引冲突仅作来源校勘，使用一般构造重建。

相关能力：依赖`vector-contract`及`disjoint-codes`；与`ps-bent-labels`对比；可与`sequence-spectrum`组合，但序列相关仍须独立转换与验收。
