# 域乘法向量阵列：全部组合单射与容量证书

## R — Reading

> “构造 GMM 型 (n, m, t) 弹性函数的关键在于向量阵列的设计.”

出处：《密码函数》第3章3.5—3.6，p.185—202，构造3.32及其证明、式(3.42)—(3.43)。本卡范围限定A/D阵列的组合单射、重量下限及实际容量；不采用定理3.37、3.41未补齐的精确界。

## I — Interpretation

多输出GMM不能只要求每一列映射是单射，还要任意非零列组合都单射。
将每行各列写为连续域幂的坐标，列组合就成为乘一个固定非零域元素。
域乘法是置换，因此每个非零组合随行索引都不重复。
A类把域元素线性嵌入一个码，不同码的非零部分互不相交，故跨码也不重复。
D类直接在u维域上排列幂，再筛掉某个输出组合重量过低的整行。
筛行保持每个组合无重复，但可用容量必须重新数。
容量不仅取决于u、m、t，还取决于多项式、坐标基和列选择。
输出应是一份合法行列表和全组合检查证书，而非一个未经限定的表格数值。
阵列合法只是GMM构造的接口条件，还没有产生完整输入划分或证明精确非线性度。

## A2 — Future Trigger

- “构造任意非零列组合都不碰撞的映射”（all nonzero combinations injective; vector array）。
- “重算D(u,m,t)容量/表3.5”（D-array capacity; enumerate valid rows）。
- “换本原多项式或列后容量为什么变了”（primitive polynomial; selected columns; basis dependence）。
- “为多输出GMM准备A阵列零件”（disjoint-code array; vectorial GMM building blocks）。
- “坐标映射各自单射，组合仍有碰撞”（componentwise injection; collision witness）。

与相邻能力的区分：不相交码卡负责生成和验码；本卡使用其码及线性同构生成阵列。前缀划分与完整GMM生成属于相邻能力，不能由本卡容量数字代替。仅需给定多输出函数验指标时使用多输出验证契约。本卡不负责A/D/L混合配置的精确N结论。

## E — Execution

**输入契约**：选择A或D模式；目标输出维数m、重量阈值t≥0；明确本原多项式、域坐标基、生成元、列指数和行索引。

- A模式：提供u长度、维数m、最小距离至少t+1的不相交码集C_j及每码一组有序基；域为GF(2^m)，映射π_j按此基线性展开。
- D模式：域为GF(2^u)，1≤m≤u，默认选择基中的连续列指数0,…,m-1。若换列，输入所选域元素并证明它们F₂线性无关；不能只凭“列不同”判定独立。
- 若缺少多项式或基，先取得明确表示或把实现选择清楚写成约定，再验证其合法；不得直接从(u,m,t)取唯一容量。

1. **验证域与坐标。** 校验多项式既约、生成元阶为2^r-1，r为相应域维数；建立非零幂表并确认无重复。记录整数编码与坐标向量转换。与源表对照时，坐标顺序差异必须解释；不能把位反转误判为不同权重分布。
2. **A模式构造。** 令γ为GF(2^m)本原元。对每个码j及a=0,…,2^m-2生成一行b_{j,a,i}=π_j(γ^{a+i})，i=0,…,m-1。π_j把多项式基的m个坐标映到码的有序基。先验证每码秩m、距离≥t+1，任意两码仅交零；不满足时停止并返回码/消息见证。未经筛距的码数量不得用于容量。
3. **A模式全称证明。** 对c≠0令q_c(γ)=Σ_i c_iγ^i。基独立保证q_c≠0；该行列组合为π_j(γ^a q_c)，随a遍历同一码全部非零字一次。码间不相交保证跨j也无重复；码距给所有组合重量≥t+1。A容量是实际合法码数J乘(2^m-1)，只代表所给码集，不称全局最优。
4. **D模式生成并筛行。** 令α为GF(2^u)本原元，ρ是域元素到u维坐标的线性同构。对a=0,…,2^u-2生成b_{a,i}=ρ(α^a v_i)，其中默认v_i=α^i。对每个c≠0计算s_{a,c}=异或_{i:c_i=1}b_{a,i}及其汉明重量。只要某个组合重量≤t，就删除整行并记录首个失败c；所有组合重量>t才保留。N等于保留行实际数量，不从原表推断。
5. **D模式全称单射证明与实际检查。** 由于所选v_i独立，每个q_c=Σc_i v_i非零；乘q_c为非零域置换，完整行集合中的组合无重复。删行只取子集，仍无重复。小规模额外枚举每个c在保留行中的像集合，检查大小等于N，记录最小重量与碰撞见证。若用户提供外部阵列，不能预设其来源合法，必须直接检查。
6. **输出和应用交接。** 交付模式、u/m/t、域多项式/基/生成元/列、完整合法行、每c的像数及最小重量、删除行和失败组合、实际容量及证明。资源math_tool.py的d-array可辅助D枚举；A模式也可按上述公式明确生成。交给GMM时还须提供从每个前缀集合到行列表的单射、真实不交完备划分，再由相邻GMM能力推谱下界。

**精确算术约定**：F₂异或和整数汉明重量，不使用浮点容差。D穷举基本工作量与(2^u-1)(2^m-1)m相关；预算不足要输出已检行范围及未检范围，不报告完整N。需要容量下界时可用已验证行数作保守下界，并明确尚未穷尽。

**完成标准**：限定表示下每个保留行所有非零组合重量>t，且对每个非零c跨保留行无重复；A模式还验证跨码不交。容量绑定完整表示，失败有行号/c/向量见证。

## B — Boundary

- 只检查m个列不够：某个非零列组合可重复或低重量。
- 本卡不证明所有输入块能填满，也不推出完整多输出函数的精确N、最优次数或高AI。
- 定理3.37/3.41的等式达到性与混合构造细节继续隔离；本卡仅交付经过证明的A/D接口与容量。
- p.201“本原多项式数量φ(u)/u”为原版校勘项，不纳入算法；GF(2^u)本原多项式数量应按独立正确计数公式处理。
- 基变化、选列或多项式变化可能改变汉明重量及N；有限域抽象同构不保证固定坐标重量不变。
- 不把某个表示下D容量与某个给定码集A容量比较提升为普遍全局最优结论。

相关能力：依赖有限域/不相交码检查；与前缀划分、GMM谱预算组合；生成完整多输出函数后必须进入多输出验证契约。
