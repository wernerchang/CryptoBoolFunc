# GMM容量选择与逐块谱预算

## R — 原文

> “这种通过联接具有多种变元个数的‘小’布尔函数而得到变元个数较‘大’的布尔函数的方式，就是布尔函数的广义级联。”

《密码函数》2.4节，p.81；构造2.44、定理2.45，p.83—85；广义级联弹性机制见定理2.50，p.90—91。只交付高重量仿射零件GMM下界机制，次数修改、奇维镶嵌和精确界扩展另行核验。

## I — 自述

- 单一尺寸的高重量系数可能不够填满选择器。
- GMM允许用不同自由后缀尺寸的仿射块补足输入空间。
- 每个尺寸有自己的一批系数，重量门槛决定可用容量。
- 在该尺寸内部必须无重复使用系数，限制单频率谱贡献。
- 跨尺寸仍可叠加，所以全局谱峰用各尺寸预算求和。
- 低重量频率在每一块都无法命中合法系数，从而保证弹性。
- 划分合法性、系数单射和谱预算是三个独立验收点。
- 次数和实测非线性度保留为成品指标，不从粗预算推断最优。

## A1 — 应用例

**原书类型：一般构造与实例。** 构造2.44选T_i={c:wt(c)>t}及单射φ_i，按完备柱状划分定义仿射块；定理2.45证明下界。原书例2.46给20元构造，本卡不将未逐位生成的原例当作本次实测。

**合成演练，非原书例题：** n=10、t=1。自由尺寸u=5/4/3的高重量池分别有26/11/4个系数。前两层各取满，第三层取2个；用`prefix-partition`的演练划分。每层按整数递增把重量>1系数分配给前缀，常数项取0。预算32+16+8=56，N≥512−28=484；已实测该确定实例N=484、至少1阶弹性、次数8。实测等号属于这个实例，并非普遍达到性定理。

## A2 — 触发与邻卡区别

1. 希望提高弹性函数非线性度：“GMM”“generalized Maiorana–McFarland”。
2. 一种块尺寸资源不足：“容量补足”“capacity allocation”。
3. 已有不同维零件要组合：“generalized concatenation”“混合块尺寸”。
4. 需要可复核谱下界：“Walsh budget”“非线性度保证”。

先由`prefix-partition`生成或检查定义域划分。相同尺寸纯仿射零件用`mm-spectrum`更直接；相同尺寸但内部Bent核不同用`orthogonal-spectrum`。多输出同时单射约束使用向量阵列卡，本卡不能逐坐标拼出多输出结论。

## E — 执行

**输入契约。** n、t为整数，目标是单输出t阶弹性；给块尺寸/数量及前缀划分，或允许自动选。给定每尺寸映射φ_u及前缀常数h_u，缺h时可明确默认0以生成合成实例。采用u为自由后缀维数，i=n−u为前缀维数；x=(p<<u)|z，z∈F₂^u。原构造2.44优先覆盖偶n≥6、u≤n/2的合法选择；超出此区间仅在重新证明的一般GMM条件下使用，不沿用“严格几乎最优”标签。

1. **算零件容量。** 对各自由维数u生成T_u={a∈F₂^u:wt(a)>t}，C_u=2^u−Σ_{j=0}^{min(t,u)}binom(u,j)。u≤t时无可用系数。C_u既是该尺寸可用系数数量，也是单射可容纳的前缀数上限。
2. **选择块数。** 找N_u满足0≤N_u≤C_u且Σ_u N_u2^u=2^n。自动策略可按u从大到小贪心：remaining=2^n，每层取min(C_u,floor(remaining/2^u))，更新remaining；只在末尾remaining=0时接受。该策略是实现约定，不宣称是原书最小二进制选择或任何目标的全局最优；失败时报告本策略不足，若需判定一般无解，应做完整整数可行性搜索而非直接断言。
3. **建立划分。** 按i=n−u递增使用`prefix-partition`，生成E_i，使S_u=E_i×F₂^u不交完备。检查真实前缀而非只用体积等式；失败即停止定义f。
4. **分配系数。** 每层建立φ_u:E_i→T_u单射，允许前缀常数h_u:E_i→F₂。对每块定义f(p,z)=φ_u(p)·z+h_u(p)。不同层可以重复数值系数，但维度必须固定且本层不能重复。
5. **逐块求谱。** 对总频率ω∈F₂^n，在u层拆ω=(β_u,α_u)，令
   W_u(ω)=Σ_{p∈E_i}(-1)^{h_u(p)+β_u·p}Σ_z(-1)^{(φ_u(p)+α_u)·z}。
   内层字符和在系数匹配时为2^u，否则0；单射使W_u为0或±2^u。由划分W_f=Σ_u W_u，因此max|W_f|≤Σ_{u:N_u>0}2^u，而非乘块数N_u。得到N_f≥2^{n-1}−Σ_{u:N_u>0}2^{u-1}。
6. **证明弹性。** wt(ω)≤t时wt(α_u)≤t，而所有φ_u(p)重量>t，每层贡献全零。包括ω=0，故平衡且至少t阶弹性。
7. **实测与输出。** 可枚举规模调用资源`math_tool.py`的`gmm`和`inspect`命令生成/分析，另核完整覆盖、系数单射、低重量谱、谱峰不超界、ANF次数。保留工具参数、位序与真值表摘要。

**完成标准。** 输出逐尺寸容量/选用数、实际划分、各φ/h、全定义生成器、逐层谱公式、N下界、实测N及至少弹性阶。若没有极值频率与同号达到证明，只报告下界；不得将等号作为默认完成结果。

## B — 边界

高重量系数不自动提供SAC，次数也未必达到n−t−1。提高t会缩小每层池，须重新分配容量和划分。任意改成非线性块后不能继续使用0/±2^u规则；必须重建残缺谱。不同尺寸预算通常是上界，不保证同频同号。多输出中每个非零组合的单射需要额外向量阵列，不由本卡每坐标单射推出。

**相关能力。** 依赖`prefix-partition`给完整划分；复用`mm-spectrum`字符正交推导；与`orthogonal-spectrum`是不同级联设计；与向量阵列卡组合后才支持多输出GMM。
