# 前缀剩余集生成不交完备划分

## R — 原文

> “给出一种使 Ei (1 ⩽ i ⩽ n − 1) 同时满足 (2.70) 式和 (2.71) 式的方法。”

《密码函数》2.4节，定义2.41后说明(4)，p.81—82。两式分别要求S_i=E_i×F₂^{n-i}不交与覆盖，不能以总体积相等代替二者。

## I — 自述

- 一个长度i的前缀代表大小2^{n-i}的整块输入。
- 选定短前缀后，其所有延长前缀都已被覆盖，不能再选。
- 将尚未使用的前缀扩展到下一个长度，再从中选下一批。
- 按深度递增处理，就自然保证不同尺寸块不相交。
- 总体积足够只是一项检查，剩余集递推才给出实际划分。
- 最后一层必须用完全部剩余前缀，否则仍有输入未定义。
- 此卡只完成定义域划分，不保证块上的函数具有任何密码性质。

## A1 — 应用例

**原书例题：例2.42，p.82。** 四元输入用一个3元、一个2元和两个1元零件级联。对应前缀E₁={1}、E₂={00}、E₃={010,011}；块大小8+4+2+2=16，前缀互不成为另一个的祖先，覆盖完整空间。

**合成演练，非原书例题：** n=10，自由后缀尺寸u=5/4/3，各需要26/11/2个块，即前缀长度i=5/6/7。先取长度5最小的26个前缀0…25；剩余26…31扩成长度6的52…63，取52…62共11个；余下63扩成长度7的126、127，全部取走。体积26×32+11×16+2×8=1024，无重叠或遗漏。这一具体位序/选最小策略属于实现约定。

## A2 — 触发与邻卡区别

1. 多种尺寸级联：“变长度块”“variable-size concatenation”。
2. 只有体积等式但缺实际集合：“构造E_i”“prefix partition”。
3. 函数分段重叠或缺输入：“overlap”“incomplete cover”。
4. 希望可复现地生成柱状块：“dyadic blocks”“前缀剩余集”。

后续在每块安排高重量仿射系数使用`gmm-budget`；固定长度零件不必动用本卡，使用`mm-spectrum`或`orthogonal-spectrum`。本卡不会替用户选择最优密码指标所需块数，仅验证或实现给定合法数量。

## E — 执行

**输入契约。** n为正整数，给出互异深度1≤i₁<…<i_k≤n−1及非负整数N_i=|E_i|，或给自由尺寸u=n−i及数量（先转换）。明确按高位解释前缀：由p代表的块是[p·2^{n-i},(p+1)·2^{n-i})。缺n、深度或数量应询问，不推测数量。零数量可先移除；空列表不可覆盖正维空间。

1. **计数预检。** 精确计算Σ_i N_i2^{n-i}是否等于2^n，并核N_i≤2^i。任何不等返回差额，停止“完整划分”承诺；若允许部分划分必须另标partial。
2. **初始化。** 在最浅深度i₁取可用集合A₁={0,…,2^{i₁}−1}。若N_{i₁}>|A₁|则不可行。默认从A₁按整数递增取前N项作为E_{i₁}；若用户指定E，则检查其确为该深度子集及不重复。
3. **递推。** 设上一深度i、当前深度j>i。剩余R=A_i\E_i。扩展A_j={(p<< (j−i))|q:p∈R,0≤q<2^{j-i}}。检查N_j≤|A_j|，再按同样规则取E_j。重复到末层。禁止从已选短前缀的后代中选新项。
4. **结束核查。** 末层A\E必须为空。逐深度证明：已选块与仍可用前缀代表的块互不相交且并为全空间。末层余集空使所有输入被唯一覆盖。可枚举规模另逐输入检查命中次数恰1；大维可用区间排序检查相邻块端点连续、起点0终点2^n。
5. **输出。** 保存n、前缀解释、各深度E_i、每块区间、总容量、无重叠证书和完备证书。资源`math_tool.py`的`prefix`命令可辅助生成；使用`gmm`产出的块时也应独立核验此契约。

**失败分支。** 指定前缀互为祖先时返回冲突对；容量不足时返回深度/所需/可用；总体积不等返回未覆盖或超额数。任何失败都不以截断重复前缀或补零隐瞒。

**完成标准。** 每块合法、所有块不交、并等于全空间，并保留实际前缀表或等价可复现生成器。证明与实测方式分开写明；所有算术为整数。

## B — 边界

体积相等本身不能验证任意已给集合的合法性：两个相同半空间可重复计数却覆盖不全。列举巨大前缀空间可能不可行，应使用区间/树的压缩表示，并声明实现限额。任意非柱状集合不由此算法描述；码、谱或次数性质也不是定义域划分的推论。

**相关能力。** 是`gmm-budget`的实际划分依赖；与`orthogonal-spectrum`区分外部变量尺寸；输出可作为PS、校正器以外的一般分段函数构造的定义域证书，但不替代其专用数学前提。
