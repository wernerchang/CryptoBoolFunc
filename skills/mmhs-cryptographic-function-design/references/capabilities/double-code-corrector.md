# 双不相交等距码降低校正器谱峰

## R — Reading

> “设C和C′是一对不相交[u,m,t]等距码”

出处：《密码函数》4.4，构造4.41、定理4.42，书页266—267；例4.43，p.267—268。引文按原符号去除排版空格。

## I — Interpretation

单码构造用非零域幂安排仿射系数，选择器有2^m个状态但周期只有2^m-1。
因此两个状态出现同一个系数，局部Walsh贡献可能叠加成双倍谱峰。
将其中一个状态的系数换到另一不相交等距码，消除重复原像。
两码只有零向量相交，实际使用的系数又全部非零，所以替换后无碰撞。
两组非零码字重量都恰为t，因此频谱仍落在相同重量层。
输出线性项c·Y提供符号，使重量t层的总谱和消去。
由单原像得到精确谱峰，由层和得到至少t阶校正，两个证明应分开。
高次数还需检查选择器最高次数项不消失，不能只凭分段形式判断。

## A1 — Application Example

**原书worked_example：** 例4.43以n=10,m=3,u=7，GF(8)多项式x³+x+1，使用两组[7,3,4]码基：C为1110100、0111010、0011101；C′为0010111、0101110、1011100。构造后原例给N_F=448、各非零分量次数4、至少4阶校正器与3阶弹性。

**本地复核与新输入演练：** 原码基生成器已枚举1024个输入与7个分量，得到N=448、次数4、每分量校正阶至少4。将两组码同时交换前两坐标构成合法新输入，公共坐标置换保持等距重量、交集、谱峰和校正阶保证；不能据此声称每个分量恰为4阶，也不声称原书十六进制位序已逐位复刻。

## A2 — Future Trigger

- 用户已有两组不相交等距码，要设计非线性校正器：“double-code corrector / 双等距码”。
- 用户希望消除单码结构重复系数的谱峰：“remove duplicate preimage / 降低谱峰”。
- 用户要同时保留校正阶与提高非线性度：“bias order and nonlinearity tradeoff”。
- 用户要复现(10,3,4)校正器并验证全部组合：“reproduce corrector / 全分量证书”。

相邻区分：`corrector-layer-sums`验证一般校正器及源模型，本卡负责生成特定双码族；`disjoint-codes`的一般码距下界不能代替本卡“两组所有非零字都恰为同一重量t”的条件。`vector-contract`负责所有非零分量量词和次数口径。

## E — Execution

**输入契约：** 本卡限定已验证适用域m≥2，n=u+m且u>m；二元[u,m,t]等距码C与C′的m行生成矩阵，两码均满秩、每个非零字重量恰t、C∩C′={0}；GF(2^m)本原多项式、本原元γ、基(1,γ,…,γ^{m-1})；明确Y=(y₁,…,y_m)按[Y]=Σ_i y_i2^{m-i}编号，X的u个坐标顺序亦固定。n、u、m、t均为整数。

1. **检查原料。** 从两生成矩阵分别枚举2^m个码字，核验秩m、非零重量集合均为{t}、交集恰{0}；核验γ乘法阶2^m-1。任一项失败则返回缺口，不把普通最小距离码作为替代输入。
2. **建立线性同构。** 定义π(Σ_i e_iγ^{i-1})=Σ_i e_iθ_i，π′同理使用θ_i′。记录域位序与码坐标表，测试线性与零元映射；不混淆整数[Y]与域元素坐标。
3. **生成分量。** 对i=1,…,m，Y=0时令b_i(Y)=π′(γ^{i-1})，Y≠0时令b_i(Y)=π(γ^{[Y]+i-1})，域指数模2^m-1；设置f_i(Y,X)=b_i(Y)·X+y_i。对每个输入生成F=(f₁,…,f_m)。
4. **证明全部组合单原像。** 固定c≠0，q_c=Σ_i c_iγ^{i-1}≠0；系数b_c(0)=π′(q_c)，Y≠0时b_c(Y)=π(q_cγ^{[Y]})。非零Y的编号1至2^m-1覆盖非零域幂恰一次，故在C中无重复；C′的非零值不在C中，故全部2^m个系数不同。
5. **推出谱峰与非线性度。** 对X先求和，W_{f_c}(β,α)=2^uΣ_{Y:b_c(Y)=α}(-1)^{(c+β)·Y}。单原像给谱{0,±2^u}；任一实际像系数都达到非零幅值，所以精确N_F=2^{n-1}-2^{u-1}，无需把上界冒充等式。
6. **证明至少t阶校正。** 所有b_c(Y)重量恰t，所以总频率重量<t时谱逐点为零；重量=t时非零贡献只能β=0。对α遍历这一层的谱求和，得到2^uΣ_Y(-1)^{c·Y}=0。故低至t次层和全为零，校正阶至少t；是否更高需继续计算层和。
7. **证明及核验次数。** 当m≥2，GF(2^m)非零元素总和为0，故Σ_Y b_c(Y)=π′(q_c)≠0。这正是选择器全乘积项对应的X线性系数，保证每个c≠0的次数恰m+1。以ANF复算确认位序实现一致。
8. **计算证书。** 使用资源`math_tool.py`的`corrector`与`inspect`重复生成及检查，但同时保留以上代数推导。小参数全枚举；大参数交代无法穷举范围并提供统一证明。

**输出契约：** 两码生成矩阵/交集/重量证书、域多项式与基、Y编号和码位序、全部系数或其确定性生成规则、所有c的碰撞检查、三值谱幅与计数、N_F、min/max次数、所有层和及至少/恰好阶分栏。完成标准为每个前置条件有证据，所有非零输出组合均通过；缺等距性或交集证据即不得交付成功构造。

## B — Boundary

并非所有参数都有两组不相交等距码；找不到原料时应停止并报告参数缺口。校正结论只适用独立同偏差输入，不能推为通用随机源提取。至少t阶不等于恰t阶；普通坐标置换保持模型，但任意线性输入混合未必保持。高N不保证低差分、全系统安全或侧信息下不可预测性。本文的m≥2限定使最高次项求和证明明确；m=1需另行分析，不能沿用步骤7。

相关能力：依赖`disjoint-codes`的代数对象检查与`vector-contract`；组合`corrector-layer-sums`作最终概率/层和验收；不以`sequence-spectrum`的相关指标替代校正阶。
