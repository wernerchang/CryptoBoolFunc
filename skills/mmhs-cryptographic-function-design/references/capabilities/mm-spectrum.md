# MM谱构造与条件拆分

## R — 原文

> “构造 MM 型 n 元布尔函数就是把 2n−k 个 k 元仿射布尔函数级联起来。”

张卫国《密码函数》2.2节，p.63；定义2.21、构造2.22和定理2.23，p.63—66。书页对应本来源PDF页+10。这里仅采用已核查的单射MM谱、重量窗及互补配对机制。

## I — 自述

- 把输入拆成选择器Y和被线性处理的X。
- 每个Y选择一个仿射零件，其系数φ(Y)决定该零件的谱位置。
- 让φ单射，固定频率就至多得到一个非零贡献，谱峰因此精确可控。
- 让系数都远离低重量区域，就能排除相应的低重量全谱。
- h(Y)只改变这些贡献的符号，可作为后续设计自由度，但次数必须另算。
- 若还要求严格雪崩性质，需要像集在逐位取反下闭合，而非仅有高重量。
- 单射、重量限制、互补闭合分别承担不同结论，应逐项输出证书。
- 此法提供部件性质，不能单凭这些性质认定整个密码安全。

## A1 — 应用例

**原书类型：构造与证明。** p.62—63用小真值表解释仿射零件级联；构造2.22提出一般约束，定理2.23给出Plateaued、非线性度、弹性及SAC结论。具体输出须遵守构造条件，不能将任意MM映射视作该定理实例。

**合成演练，非原书例题：** n=4、k=3、Y∈F₂、X∈F₂³，φ(0)=011、φ(1)=100，h(Y)=Y+1。两系数不同且互补；重量分别2和1，因此r=1。对全部16输入计算，得到平衡、N=4、次数2，谱绝对值分布0出现12次、8出现4次；四个单比特差分方向的导数均平衡。本例只有0阶弹性保证，不报告1阶。

## A2 — 触发与邻卡区别

适用场景及语言信号：

1. 要以仿射零件构造布尔函数：“MM构造”“Maiorana–McFarland construction”。
2. 要从允许频谱位置反推映射：“指定谱支撑”“design spectral support”。
3. 要同时检查弹性与雪崩：“resilient and SAC”“严格雪崩条件”。
4. 已给φ和h，希望验证谱公式：“injective mapping”“MM spectrum certificate”。

仅分析一般函数的指标时使用指标契约/全分量检查卡；固定尺寸非线性零件且同层谱不相交时使用`orthogonal-spectrum`；零件尺寸不同则使用`prefix-partition`与`gmm-budget`。缺互补闭合不应拒绝所有MM任务，但必须撤回SAC的这一充分保证。

## E — 执行

**输入契约。** 必需n、k为整数且0<k<n；指定φ真值表（长度2^{n-k}、每项k位整数），h真值表（相同长度、0/1），目标t及是否要求SAC。若要求自动生成φ，可缺映射但必须给n、k和目标。若缺维数或SAC目标，应先询问。实现约定：Y按整数递增，x=(Y<<k)|X；位j对应整数第j位，所有加法为GF(2)异或。

1. **检查合法性。** φ取值在[0,2^k)、互不相同；h各项为0/1。失败时返回首个越界值或碰撞(Y₁,Y₂)，停止单射谱结论。若套用构造2.22，另核n≤2k。
2. **生成或检查重量窗。** 自动模式枚举e=0,…,floor(k/2)，计算整数容量C_e=Σ_{j=e}^{k-e}binom(k,j)；取最大可容纳2^{n-k}个系数的r。要求r≥t+1。把合法系数分成{c,c⊕(2^k−1)}配对，选2^{n-k-1}对并赋给不同Y；容量不足则返回不可行证据。给定映射时直接报告最小系数重量及所满足的窗口，不能把其实际保证阶混写成最优r。
3. **构造函数。** 对每个(Y,X)，计算f=parity(φ[Y]&X)⊕h[Y]。输出生成器或完整真值表；改变h后重新计算ANF次数。
4. **重建谱。** 对频率(β,α)，先对X求和。若α不在φ像中，W=0；若α=φ(Y₀)，W=2^k(-1)^{h(Y₀)+parity(β&Y₀)}。故谱为{0,±2^k}，精确N=2^{n-1}−2^{k-1}。每个低重量频率wt(β)+wt(α)≤t都有wt(α)≤t，不可能命中重量>t的像，因而至少t阶弹性。
5. **独立核SAC。** 若要求SAC，检查像集互补闭合。Y差分非零时，单射使φ(Y)⊕φ(Y+b)非零，X字符和消失。只翻X第j位时，自相关为2^kΣ_Y(-1)^{φ(Y)_j}，互补对使其抵消。若闭合不满足，应直接枚举全部单比特方向验证，或报告“SAC未由该构造条件保证”，不凭三值谱断言。
6. **输出并复核。** 使用整数FWHT对可枚举规模核对公式、Parseval ΣW²=2^{2n}、N、低重量零谱和所需SAC。可使用资源`math_tool.py`的`mm`与`inspect`命令；命令参数依工具帮助，工具不能替代上述推导。

**完成标准。** 输出参数/位序、φ及h、单射和重量/互补证书、f、精确N与至少弹性阶、SAC证明或明确未保证状态。计算采用整数，零容差；超出枚举预算时仅对结构证明覆盖的项目报告结论，并注明未全谱实测。

## B — 边界

φ碰撞时每频率可能多原像叠加，精确谱峰公式立即失效。h的自由选择不保证次数或AI/FAI最优。互补闭合只是本卡用于保证SAC的充分机制；没有它也可能存在SAC，但需另验。普通MM在n=2k时可Bent，Bent不平衡，不能同时要求正阶弹性。更高阶扩散、差分均匀度与密码系统安全均需另外分析。

**相关能力。** 与`orthogonal-spectrum`对比：后者允许非线性核；与`gmm-budget`组合：本卡单射字符和是其逐块谱计算的基础；无需生成不相交码即可独立使用。
