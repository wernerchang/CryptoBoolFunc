# DS恒等R子族：谱支撑搬运与正交级联

## R — Reading

> “这2^s个函数的频谱之所以是正交的, 是因为经过仿射变换后它们的非零频谱值对应的向量都分别分布在2^s个不同的不相交码中。”

出处：《密码函数》3.4，构造3.27、定理3.28，书页182—184；引文将原上标排成可读指数。本卡仅交付R_z=I的子族。独立审阅与计算发现原任意可逆R分支的支撑论证不成立，反例谱峰224而非32；此一般分支已隔离，不作为可用定理引用。

## I — Interpretation

从奇数k维AB置换G出发，所有非零分量既平衡又半Bent。
增加s个忽略的变量后，频谱幅值乘2^s，支撑集中到一个k维子空间。
本卡固定R_z=I，为每个选择器z设计一个可逆输入变换，把支撑搬到码C_z中。
各码只在零点相交，而平衡分量的零频谱为零。
所以搬运后的真正非零支撑两两不相交。
级联的谱是各块谱加权求和，但任何频率最多有一块贡献。
幅值不会随块数增加，最终仍保持指定半Bent幅值。
所有非零分量同时使用这一结构，得到联合平衡的多输出函数。

## A1 — Application Example

**原书worked_example：** 例3.29，p.184—185，n=9、s=k=3。原例给AB种子表和8个搬运矩阵，但p.184的A₀₀₀与A₀₀₁印刷矩阵完全相同。不得把该矩阵表直接当作已验证正例。

**新生成演练：** 按一般构造重新用GF(8)乘法生成8个M_z，取R_z=I；种子为3位AB置换。完整枚举512输入和7分量，输出向量各64次，谱均为{0,±32}，N_F=240。该结果证明这一生成实例，未替印刷矩阵表作无声修正。

## A2 — Future Trigger

- 希望构造奇数维平衡半Bent多输出函数：“DS construction / 平衡半Bent”。
- 已有AB置换，想增加输入维数：“extend an AB seed / 扩维”。
- 级联后谱峰失控，需让块支撑互斥：“disjoint spectral supports / 搬运频谱”。
- 要核查输入矩阵的逆转置方向：“inverse transpose / 支撑变换证书”。

与相邻能力区分：`ps-recursive-balance`依靠自由码补支撑实现平衡，不负责维持本卡的半Bent幅值；`orthogonal-spectrum`是单输出零件层接口；`vector-contract`检查全部非零分量，不能代替本卡的生成算法。

## E — Execution

**输入契约：** 奇数k≥3，整数s≥k，n=2s+k；AB置换G:F₂^k→F₂^k的真值表或生成式；2^s个k维码C_z⊂F₂^{k+s}，两两交仅零；每码生成矩阵(I_k|M_z)；所有R_z必须为I_s。用户指定非恒等R时停止并说明超出本卡已证范围，不静默替换为I。所有基、位序及行向量约定必须显式记录。

1. **验证核。** 枚举G确认是置换；对每个c≠0检查W_{c·G}(0)=0及谱取值{0,±2^{(k+1)/2}}。仅一个坐标半Bent不够，核失败则停止。
2. **生成合法图码。** 可在GF(2^s)中选独立k维子空间U，以域乘法z定义线性映射U→GF(2^s)，得C_z={(a,az)}。对不同z，a(z+z')=0保证交仅零。将映射转成M_z；可取R_z=I。任何重复码或秩不足均返回失败。
3. **定义扩展与变换。** 令H(X,Y)=G(X)，v=(X,Y)为行向量；固定A_z=[[I_k,M_z],[0,I_s]]，并令H_z(v)=H(v A_z^{-T})。特征2中A_z²=I，故A_z^{-1}=A_z；谱变换为W_{c·H_z}(a)=W_{c·H}(aA_z)。写a=(p,q)，非零谱要求q=pM_z，所以实际支撑包含于图码C_z。若右下块改为任意R_z，则条件变成q=pM_z R_z^{-1}，原图码不交条件不足够；不得沿用本步骤。
4. **构造F。** 以z为s位选择器，F(z,v)=H_z(v)。按固定字典序生成真值表。不要因原例矩阵表有冲突而跳过这一层重新生成。
5. **证明谱。** 对固定c≠0，H分量的谱只在新增频率为零时非零，幅值为2^{s+(k+1)/2}。搬运后支撑落于C_z\{0}；固定频率时最多一块贡献，因此F分量谱仍为0或±2^{(n+1)/2}。零频全为零保证联合平衡。
6. **实测及完成。** 小参数用资源`math_tool.py`的`ds`及`inspect`检查所有分量、输出计数、码交集和矩阵逆关系；大维提供统一证明及有限测试范围。

**输出契约：** n,k,s、G、域表示、M_z/R_z或确定性生成器、所有矩阵的秩/逆证书、支撑不交证明、分量谱取值和计数、N_F=2^{n-1}-2^{(n-1)/2}、次数实测值。完成标准是所有前置条件通过，全部2^k-1个分量受同一证明约束，实测与理论不冲突；次数不由本卡自动宣称最优。

## B — Boundary

本卡不承诺低差分或同维置换，最终n通常大于k。不要把“AB核”替换为任意半Bent坐标集；需要所有非零组合半Bent且平衡。支撑交零只在零频确为零时才足够。不得使用例3.29重复矩阵或原任意可逆R分支作默认参数；若需原表逐位复现须先单独校勘。输入可逆变换保持谱幅值，不自动保持任意坐标弹性。反例k=s=3、非零z取R_z=M_z时，7块都退成G(X+Y)，谱峰224；该分支须重新设计和证明。

相关能力：依赖`vector-contract`与`disjoint-codes`；对比`ps-recursive-balance`；组合`sequence-spectrum`时另外验证函数和的谱和对齐定义。
