# Bent函数正规性：无重复子空间枚举与陪集剪枝

## R — Reading

> “确定了 Fn2 中所有 k 维仿射子空间之后, 可以通过遍历所有的这些仿射子空间来判断布尔函数 f ∈ Bn 的 k-正规性. 这种方法直白而朴实, 但有时并无必要.”

出处：《密码函数》第2章2.9，书页138—139，引理2.88、定理2.89、推论2.90及算法2.91；无重复子空间表示见p.136—137的引理2.87。本卡不声称本项目已测试特定GJB代码。

## I — Interpretation

正规性寻找函数限制为常值的半维仿射子空间。
同一线性子空间有很多不同基，必须先去重，避免把基的数量当作子空间数量。
固定方向C后，它的各陪集把全空间分开；每个陪集只需计算函数值为1的数量。
常值陪集的重量是0或2^{n/2}，平衡陪集的重量是2^{n/2-1}。
Bent谱能量限制使一个常值陪集已经用尽该方向允许的平方偏差。
因此同方向其他陪集都应平衡；反过来，出现非常值且不平衡的陪集就能排除其余陪集为常值。
利用这一结论可少算一些陪集，但必须先确认输入真为Bent且方向恰半维。
剪枝应与朴素枚举对照，不能把搜索提前停止当作不存在证明。

## A1 — Application Example

**书中算法**：算法2.91，p.139，输入Bent真值表，输出正规点，利用陪集重量剪枝。它是算法说明，不冒充作者执行的实验。

**本项目合成演练**：n=4，f(x)=x₀x₁+x₂x₃。穷举所有2维子空间并按元素集合去重，得35个子空间；分别运行朴素全陪集检查与能量剪枝，正规仿射子空间列表一致。该演练已执行，记录于normality_n4。它验证集合去重与剪枝，不证明某个GJB生成实现正确。

## A2 — Future Trigger

- “判定这个Bent函数是否正规”（normal Bent; normality test）。
- “列出全部半维常值仿射子空间”（constant restriction; affine subspaces）。
- “子空间枚举重复很多，怎样去重/剪枝”（deduplicate subspaces; coset pruning）。
- “我提前break是否会漏掉正规点”（pruning completeness; exhaustive search）。

与相邻能力的区分：零谱搬运在频域找基以获得弹性；本卡在输入域找常值限制。只需要非线性度或Bent判定时，用谱检查即可，不必进行本卡的指数规模子空间搜索。要求一般k正规性或非Bent输入时，不套本卡半维Bent剪枝。

## E — Execution

**输入契约**：偶数n≥4、长度2^n的二元真值表、明确位序；目标固定为n/2维正规仿射子空间。输出范围需选择“判定存在”或“列出全部”。如果输入只给名称不提供生成法，不能凭名称认定Bent。

1. **检查Bent前提。** 精确计算全部Walsh谱，验证每个幅值等于2^{n/2}。有任何频率不符时停止Bent剪枝分支，报告失败频率；如用户仍需查正规性，只能转到朴素完整搜索，并明确改变了适用算法。
2. **无重复枚举半维线性方向。** 对k=n/2，可枚举k个独立向量，计算它们所有2^k个异或和，将结果排序成元组作为方向C的规范键，仅保留每个键一次。也可使用已验证的行最简基规范化，但必须说明规范与重复消除方法。本项目资源采用的去重策略应如实写明，不把它称作已测试GJB实现。检查每个方向|C|=2^k且对异或闭合。
3. **建立唯一陪集代表。** 维护未覆盖输入集合；每次取其中固定次序最小的e，生成e+C并从未覆盖集合删去，直到耗尽。检查得到2^{n-k}个两两不交、并为全空间的陪集。可用补空间替代，但须提供补空间生成矩阵及直和证书。
4. **按重量判断及剪枝。** 对每个陪集求w_e=Σ_{x∈e+C}f(x)。若w_e为0或2^k，记录该仿射子空间及常值；若只需存在性，可结束全搜索并返回见证。若0<w_e<2^k且w_e≠2^{k-1}，停止当前C方向剩余陪集搜索，因为其他陪集不可能常值。平衡则继续。保存已找到的正规点，不因后续分支丢弃结果。
5. **解释剪枝依据。** 引理2.88在Bent与k=n/2条件下给Σ_e(2^k-2w_e)^2=2^n。一个常值项已等于2^n，其他项都为零，故其他陪集必平衡。若已知一个非常值非平衡项，其平方偏差正且小于2^n，任何其他常值项将导致总能量超出，故可排除。
6. **检查输出去重和完整性。** 正规仿射子空间也以排序后的元素集合为键去重。小规模必须与朴素全方向、全陪集结果对照；大规模受预算限制中断时，输出已遍历方向数、未遍历部分，不给全局“不正规”结论。资源math_tool.py的normality可辅助，输出仍须包含枚举方法和范围。

**输出契约**：n、Bent谱证书、方向枚举/去重方式、方向数、已评估及剪枝陪集数、正规仿射子空间元素或基与代表、常值、搜索是否完备。固定整数重量，不采用浮点相等判断。

## B — Boundary

- 剪枝定理只在已验证Bent、半维方向上启用，不能直接用于一般函数或任意k。
- 全部k维子空间数量增长很快；局部搜索未找到常值限制不等于不正规。
- “正规点”应指给定基与代表所描述的完整仿射子空间，不混淆为单个输入向量。
- 本卡提供集合去重枚举的可执行版本，保留书中GJB为参考；未测特定GJB生成器不写成已通过。
- 正规性是结构性质，不自动表示密码指标较优或证明非线性度。

相关能力：依赖单输出谱检查；可与零谱搬运组合做结构分析，二者不互相替代。
